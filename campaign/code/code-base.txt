# Paths: a fork path is relative to the fork root (campaigns/2026-10-16-chang-bitlinear/code);
# a source path is relative to the lab root (the directory that holds reference-code/).
# Each fork file is a byte-for-byte copy of its source. Files under chang/ are never edited.
#
# Format: lines starting with '#' are comments; fields are separated by two spaces.
#   file  <sha256 of the bytes>  <fork path>  <source path>
#   tree  <tree hash>  <source tree>  files=<number of files listed>
#
# Tree hash method (HGQ2 snapshot): walk <source tree> recursively. Keep regular files only
# (symbolic links and directories are skipped). Exclude every path that has a directory
# component named __pycache__ and every file whose name ends in .pyc. For each kept file form
# the line "<sha256 hex of its bytes>  <path relative to the tree, '/' separators>" followed by a
# single newline. Sort the lines by the relative path, compared as UTF-8 bytes. The tree hash
# is the sha256 of the concatenation of the sorted lines, encoded as UTF-8. This is the format
# of preflight/env/lock/hgq2-0.1.9-installed-files.sha256 (sorted by path); here only its sha256
# is recorded, and gates/g01_base.py recomputes it.
